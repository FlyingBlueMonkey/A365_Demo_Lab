# Python OpenAI Agent

This project is a small Python demonstration of the OpenAI Agents SDK. It
creates a security architecture assistant, sends it a fixed request for a
five-item security review checklist, and prints the assistant's response to
the terminal.

The assistant is configured to provide concise, technically precise guidance,
distinguish verified facts from suggestions, and avoid revealing credentials,
tokens, secrets, or hidden configuration. The current example does not yet
register or call external tools; its prompt discusses how a Python AI agent
could call them.

This standalone sample has no Agent 365 dependency. For the same checklist
using local inference without an OpenAI API key, see
[python-ollama-agent/readme.md](../python-ollama-agent/readme.md). For telemetry
integration, see [a365-python-openai-agent/readme.md](../a365-python-openai-agent/readme.md).
That sample uses the supported Microsoft OpenTelemetry distribution with
automatic OpenAI Agents instrumentation; this standalone baseline needs no
A365 packages or migration.
The [lab README](../readme.md#enable-and-set-up-the-a365-cli) includes discrete
A365 CLI setup steps; they are not required to run this project.

## Requirements

- Python 3.9 or newer
- An OpenAI API key
- PowerShell on Windows, or an equivalent shell on another platform

Python 3.10 or newer is recommended. Python 3.9 requires the
`eval_type_backport` dependency included conditionally in `requirements.txt`.

## Setup

From this directory, create and activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install the dependencies:

```powershell
python -m pip install -r requirements.txt
```

Set the API key in the current PowerShell session:

```powershell
$env:OPENAI_API_KEY = "your-api-key"
```

To persist configuration in a local `.env` file, create `.env` in this directory
with the following contents instead. Keep this file private and do not commit
it to source control:

```dotenv
OPENAI_API_KEY=your-api-key
OPENAI_MODEL=gpt-4.1-mini
```

`OPENAI_MODEL` is optional and defaults to `gpt-4.1-mini`.

## Run

With the virtual environment activated:

```powershell
python app.py
```

Or run directly through the virtual environment without activating it:

```powershell
.\.venv\Scripts\python.exe app.py
```

The program prints a five-item security review checklist generated by the
configured model. If `OPENAI_API_KEY` is missing, the OpenAI client will stop
before it can generate a response.

## Project files

- [app.py](app.py) builds the agent and runs the example request.
- [requirements.txt](requirements.txt) lists the Agents SDK, OpenAI SDK compatibility pin, and
	environment-variable loader.

## Extending the demo

The next natural extension is to define one or more typed tools and register
them with the agent. Tool implementations should validate their inputs,
restrict access to the minimum required resources, avoid returning secrets,
and make side effects explicit before they are enabled in production.
